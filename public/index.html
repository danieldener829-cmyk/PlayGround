⚙️ Como funciona

Feito pra quem só quer ver o bot online, sem VPS, sem terminal.

📦 1. Upload inteligente

Extraímos o ZIP, ignoramos __MACOSX e listamos os arquivos. Se achar package.json, roda npm install. Se achar requirements.txt, roda pip install.

🔍 2. Detecção automática

Procuramos nessa ordem: seu campo “principal” → package.json main → index.js, bot.js, main.js, src/index.js → bot.py, main.py, app.py, index.py.

📡 3. Processo isolado + logs

Cada bot roda num processo próprio com DISCORD_TOKEN injetado. Logs ficam salvos, dá pra reiniciar com 1 clique.

❓ Dúvidas rápidas

Meu bot é discord.js v14, funciona?

Sim. Se o ZIP tem package.json com discord.js, instalamos tudo com npm install e rodamos com Node 22.

E se for Python?

Sim. Com requirements.txt (ex: discord.py) instalamos e rodamos com python3 bot.py.

Onde coloco o token?

No campo token ao subir, ou depois em Config. Nunca commite o token no ZIP — use process.env.DISCORD_TOKEN ou os.getenv("DISCORD_TOKEN").
