🚀 Como funciona em 3 passos

    

      
1. Ligue
Escolha Buildroot (rápido), KolibriOS (gráfico) ou FreeDOS. O boot baixa poucos MB uma vez.

      
2. Use
Clique na tela para o teclado, digite no serial ou use o mouse no KolibriOS. Salve o estado para continuar depois.

      
3. Expanda
Precisa de Debian completo ou desktop? Use o Lab externo ou conecte seu servidor na seção Servidor.

🔌 Quer Windows / Ubuntu real com rede, disco e desktop completo?

    
Um site estático não consegue hospedar VPS grátis para todo mundo — precisa de servidor, licença Windows e banda. Você tem 2 caminhos reais:

    

      
1. Conectar seu servidor
Rode um container e cole a URL abaixo para embutir aqui via iframe/noVNC.

        docker run -p 3000:3000 lscr.io/linuxserver/webtop:ubuntu-xfce
        docker run -p 7681:7681 tsl0922/ttyd

🪟 PC virtual Windows 10 para VNC Viewer

        
Monte um Windows 10 de verdade no seu computador/servidor e acesse pelo RealVNC Viewer (ou qualquer VNC). Este site não hospeda Windows — ele gera os comandos e o painel de conexão.

      

    

    
⚖️ Licença: use sua própria licença do Windows 10 ou a ISO de avaliação da Microsoft (90 dias, grátis para testes). Não distribuímos imagens do Windows. O container dockur/windows baixa o Windows dos servidores da Microsoft e exige aceite do EULA.

    

      
A. Docker (mais fácil)
1 comando e o Windows 10 sobe com tela web + VNC. Ideal para testar.
docker run -d --name win10 -p 8006:8006 -p 5900:5900 -e RAM_SIZE=4G -e CPU_CORES=2 dockur/windows

      
B. QEMU/KVM (manual)
Controle total com sua ISO. VNC na porta 5900 para o VNC Viewer.
qemu-system-x86_64 -m 4096 -smp 2 -hda win10.qcow2 -cdrom Win10.iso -boot d -vnc :0 -usbdevice tablet

      
C. No VNC Viewer
No app RealVNC Viewer digite SEU-IP:5900, aceite o aviso e informe a senha do VNC. Ex: 192.168.1.50:5900.

🔌 Conectar meu VNC (Viewer / Web)

      

        
        
        
        
        
        
      

      SEU-IP:5900
      
    
        
  • 📲 RealVNC Viewer: Arquivo → Nova conexão → endereço IP:5900 → conecte e digite a senha. Marque “Lembrar” só em PC pessoal.
    • 
        
  • 🌐 Via Web: abre o cliente noVNC apontando para seu servidor (exige websockify ou a tela web do container na porta 8006).
    • 
        
  • 🔒 Nunca exponha VNC sem senha na internet — use VPN (Tailscale/WireGuard) ou túnel SSH: ssh -L 5900:localhost:5900 usuario@seu-servidor e conecte em localhost:5900.
    • 
        
  • 🧱 No Windows da VM: instale o TightVNC Server, libere a porta no Firewall e defina senha forte.

Sobre o NuvemOS

    
Interface e textos 100% originais, inspirados apenas na ideia de “rodar sistemas no navegador”. Os sistemas executados são projetos abertos de terceiros carregados dos sites oficiais: WebVM (Leaning Technologies), JSLinux (Fabrice Bellard) e v86 (copy.sh). Sem afiliação com OnWorks, Microsoft ou Canonical.

    
É grátis? Tem limite?
Sim, tudo aqui roda no seu navegador, então não há fila nem custo de servidor. O limite é o seu dispositivo: VMs pedem 64-256 MB de RAM e o primeiro boot baixa a imagem.

    
Por que não tem Windows 10/11 direto?
Licença da Microsoft: não posso distribuir Windows fechado num site estático. Uso ReactOS (aberto, compatível) + guia para você rodar seu Windows licenciado no seu servidor.

    
Meus dados ficam salvos?
Estado da VM só se você clicar em “Salvar estado”. Favoritos e newsletter ficam no localStorage do seu navegador. Nada vai para servidor nosso — nem temos um.
