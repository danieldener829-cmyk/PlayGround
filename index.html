Dúvidas frequentes

Como registro um .com.br de verdade?

No Brasil, o registro oficial é feito pelo Registro.br (NIC.br). Você cria uma conta com CPF/CNPJ, busca o domínio, paga (~R$ 40/ano) e aponta os DNS para nossa hospedagem (ex.: ns1.brhost.com.br). Se contratar aqui, fazemos esse processo para você sem custo extra de configuração.

Posso trazer meu domínio de outro lugar?

Sim! Basta alterar os nameservers para os nossos ou apontar o registro A. Oferecemos migração gratuita e seu site não sai do ar.

O criador desta página publica de verdade?

Não — é uma demonstração funcional no navegador. O site gerado fica salvo no seu dispositivo com preview real em HTML. Para publicar de verdade você precisa de um plano + DNS apontado. Use o botão “Exportar” para baixar o HTML e enviar para qualquer hospedagem.

Quais formas de pagamento?

PIX (aprovação instantânea), cartão de crédito em até 12×, boleto e transferência. Nota fiscal para CNPJ.

Existe garantia?

Sim: 30 dias de garantia incondicional + 99,9% de SLA de uptime.
