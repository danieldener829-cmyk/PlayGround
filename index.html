FAQ

Perguntas frequentes

Como acesso meu PC Virtual?

Pelo botão “Acessar PC” no painel (console web quando o backend estiver conectado) ou via RDP com IP, usuário e senha fornecidos após provisionamento real.

Uma máquina é criada automaticamente ao contratar?

Não neste front-end. O provisionamento real só ocorre com backend de virtualização conectado. Até lá, o painel exibe dados de demonstração claramente sinalizados.

Quais formas de pagamento?

Estrutura pronta para PIX e cartão via gateway real (ex.: Stripe, Mercado Pago, Asaas). Nenhuma cobrança real é processada nesta versão demo.

Posso trocar de plano?

Sim. Upgrade/downgrade altera vCPU, RAM e disco no próximo ciclo, sujeito à disponibilidade do backend.

Como funciona o suporte?

Área de suporte no painel com abertura de tickets. Planos Pro/Ultra têm fila prioritária.
